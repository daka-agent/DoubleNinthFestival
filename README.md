# 登高 · 重阳

> 十站山路，十位我们从小在屏幕上认识的老人。
> 他们中有人最怕的，不是老，也不是死，是**被忘记**。

**在线体验**：https://daka-agent.github.io/DoubleNinthFestival/

---

## 这是什么

一部给 2026 年重阳节（10 月 18 日，农历九月初九）做的单页作品。

除夕、清明、中元、重阳是四个祭祖的节日。
**但只有重阳敬的是还在世的人**——其他三个敬的是先人，只有重阳敬的是眼前这位。

所以这部作品不讲道理，只做一件事：带你在屏幕上重遇十位老人，
每人留下一件物件、一句话。

## 怎么玩

- 点「开始登山」，也可以左右滑动屏幕、或按键盘方向键
- 每站先出现一件物件剪影——先认，再看是谁
- 每站可以点开「知道了」，看这个人是谁、那句话从哪来
- 十站走完到山顶，那里有三个问题，建议你真的拿去问家里人

## 主线

**怕被忘记 → 我要你认我 → 被忘记才是死**

- 友藏：「我的事情千万不要忘记，小丸子。」
- 老爷爷：「孩子，我是你爷爷。」（他从头到尾没有名字）
- 可可：「真正的死亡，是世界上再没有人记得你。」

## 落点

重阳是四个祭祖节里唯一敬活人的那个。
所以最后不喊口号，只给一个动作：**趁他还在，认他、记得他。**

打得完的电话，别等到来不及。
